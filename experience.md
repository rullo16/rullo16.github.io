<h3>Key Contributions & Technical Achievements:</h3>
<ul>
    <li>
        <strong>High-Fidelity Simulation Environment:</strong> I engineered a detailed, physics-based 3D simulation in Unity and C#, creating a challenging testbed for drone navigation tasks. The environment was integrated with a Python training pipeline via the Unity ML-Agents toolkit, specifically using the PettingZoo Parallel API for multi-agent communication.

    <li>
        <strong>Advanced Continuous Control Agent:</strong> I architected and implemented a continuous control agent based on the Soft Actor-Critic (SAC) algorithm. To manage the complexity of multi-agent dynamics, I adopted a Centralised Training with Decentralised Execution (CTDE) paradigm, developing a custom centralised critic network in PyTorch that enables agents to share state information during training, facilitating more effective policy coordination.
    </li>
    <li>
        <strong>Sophisticated Reward Engineering & Exploration:</strong> A key challenge was solving the sparse reward and exploration problem. I designed and tuned a hybrid reward function that combined large, sparse terminal rewards with dense, potential-based progress rewards. To break out of "safe" but unproductive local optima, I successfully integrated an Intrinsic Curiosity Motivation (ICM) module, which provided an additional exploration bonus and enabled the agent to discover the goal state.
    </li>
    <li>
        <strong> Optimised Perception with Knowledge Distillation:</strong> To improve the agent's perception from first-person camera feeds, I implemented a Knowledge Distillation pipeline. This technique involved distilling features from a powerful, pre-trained vision model (VIP) into the agent's much smaller convolutional feature extractor, thereby significantly enhancing the quality of the learned state representations without incurring the high computational cost associated with a large network.
    </li>
    <li>

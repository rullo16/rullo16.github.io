<h1>Projects</h1>

<h2>Developing a Multi-Task Deep Reinforcement Learning Agent to Solve Optimization and Control Problems</h2> 
<p>Developing a 3D environment inspired by NASA's work on an air highway, where drones navigate to reach designated goals. The idea is to apply Deep Reinforcement Learning to flocking, an optimization and control problem, to observe how such techniques solve these challenges. The environment has been developed using the Unity engine, leveraging the ML-Agents library. An implementation of the DeepMind Dreamer model has been developed to solve this environment, while also exploring other models such as Distral.</p> 

<h2>Extending Adversarial MARL in Rescue Missions and Safe-Critic Environments</h2>
<p>Extended the work done by AdverSAR by building a 3D dynamic environment using Unity and adapting the algorithm to an additional dimension.</p>

<h2>AutonomousProcgen</h2> 
<p>A Reinforcement Learning Agent designed to solve OpenAI Procgen Benchmark environments using Proximal Policy Optimization while integrating exploration techniques such as Network Distillation.</p> 

<h2>Norm Emergence in Multi-Agent Systems Using Deep Reinforcement Learning</h2> 
<p>Simulated complex road intersection scenarios using Unity and C#, training agents with Proximal Policy Optimization and Soft Actor-Critic algorithms.</p>

<h2>Adversarial Learning for Fairness in MARL: Mitigating Discrimination in Cooperative Environments</h2> 
<p>Implemented a FAIR-DQN model by incorporating the Fair Adversarial Discriminative model into the DQN framework. This approach also integrated critical components from the one-network adversarial approach and was trained in a cooperative environment where one agent had a deficit in capabilities compared to others.</p> 

<h2>Art Description & Classification</h2> 
<p>Developed an Art Critic Model aiming to be a sophisticated computational tool capable of analyzing art pieces, particularly paintings, and generating critique-like descriptions of them. Additionally, the model provides functionality to use the generated descriptions to select a different artistic style, resulting in the generation of a new image embodying the chosen style.</p>
